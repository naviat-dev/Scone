Piracy Is Not A Victimless Crime

Scone is a tool that reads, analyzes, and reformats scenery designed for Microsoft Flight Simulator.
It is intended for use only with legally obtained scenery and should not be used to circumvent copyright protections.
If you are not sure whether your scenery is legally obtained, you should not use Scone with it.
If the creator of the scenery has not granted permission for modifications, you should not use Scone with it.
